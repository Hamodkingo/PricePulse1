# PricePulse AI

SaaS platform for monitoring competitor product prices and receiving instant Telegram alerts.

## Setup
1. Run `supabase/migrations/001_schema.sql` in your Supabase SQL Editor.
2. Add environment variables in Vercel (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `TELEGRAM_BOT_TOKEN`).
3. Deploy on Vercel.
